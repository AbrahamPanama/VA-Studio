# Getting help with VA Studio

VA Studio is developed by VA Cards. It is based on Inkscape but it is not an
Inkscape release, so please do not report VA Studio problems to the Inkscape
project.

## Report a problem

- Support and problem reports: the VA Studio support address, published
  with the first public release.
- Please include the VA Studio version and build number (Help > About VA Studio),
  your operating system and version, the steps that lead to the problem and, if
  you can share it, a file that shows it.
- After a crash VA Studio shows a backtrace and tries to save copies of unsaved
  documents. Include the backtrace in your report. The emergency copies stay on
  your computer; VA Studio never sends crash data anywhere by itself.

## Security problems

Do not report security vulnerabilities in public issues. Follow `SECURITY.md`.

## Source code and licenses

VA Studio is free software under the GNU General Public License. `SOURCE.md`
explains how to obtain the source code of each release, and
`THIRD-PARTY-NOTICES.md` lists the third-party components and their licenses.

## Inkscape documentation

Most drawing features come from Inkscape. The Help menu links to the Inkscape
manual, FAQ and keyboard reference; those links are marked "upstream Inkscape"
and describe Inkscape, which can differ from VA Studio.
